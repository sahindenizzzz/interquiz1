# InterQuiz 🧠

An interactive quiz web application built with Node.js and HTML/CSS/JavaScript.

## Features
- Multiple choice quiz interface
- Score tracking
- Responsive design

## Tech Stack
- Node.js / Express
- HTML, CSS, JavaScript

## How to Run
1. Clone the repo
2. Run `npm install`
3. Run `node server.js`
4. Open http://localhost:3000
